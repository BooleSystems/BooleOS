Bem vindo ao NullOS!
Digite help no shell.

Comandos disponiveis:
  help           esta mensagem
  uname          versao do sistema
  fetch          info do sistema
  ps             tabela de processos
  mem            uso de memoria
  echo <texto>   imprime texto
  kill <pid>     encerra processo
  run <prog>     executa programa
  edit <arquivo> abre editor de texto
  clear          limpa a tela
  exit           encerra o shell

Editor de texto (edit):
  Setas          navegar
  Ctrl+S         salvar
  Ctrl+Q         sair

Arquivos na ramfs: init, spintest, shell, edit, readme.txt
